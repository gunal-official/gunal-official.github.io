## 🚀 Key Features

- **Theme Toggle:** Seamless Dark Mode and Light Mode with persistence in `localStorage`.
- **Dynamic Hero Section:** Dynamic typewriter role cycling, real-time status pill, quick stats counters, and direct resume download.
- **Career & Academic Timeline:** Filterable timeline detailing professional experience at Pixselo Technologies alongside B.Tech and Diploma achievements.
- **Categorized Skills Matrix:** Interactive filter tabs covering ML & GenAI, Data Wrangling, BI & Visualization, Cloud & Databases, and Web Development.
- **Featured Projects Showcase:** Interactive filtering (All, Generative AI, Machine Learning, Data Analytics) with live Streamlit demos, GitHub repositories, and interactive architectural detail modals.
- **Verified Credentials:** Showcasing professional certifications from IBM (Data Science, Generative AI), Google (Data Analytics), and AWS (Machine Learning).
- **One-Click Contact:** One-click clipboard copy for email and phone, quick contact links, and interactive contact message form.
- **Zero-Dependency Architecture:** Pure semantic HTML5, modern CSS3 with custom properties, and performant Vanilla JavaScript for lightning-fast 100/100 Lighthouse performance.
