## 🧑‍💻 About

This portfolio represents my transition into **Agentic AI Engineering** — showcasing hands-on projects in LLM-powered applications, Retrieval-Augmented Generation (RAG) pipelines, and agentic workflows built with Python, LangChain, and vector databases like FAISS.

It also reflects my background as a full-stack Web Developer, blending software engineering fundamentals with modern AI development.

## ✨ Features

- Fully responsive design (desktop, laptop, tablet, and mobile)
- Smooth scroll navigation with anchor links
- Interactive hamburger menu for smaller screens
- Downloadable CV/Resume
- Direct links to GitHub and LinkedIn
- Project showcase with GitHub & live demo links
- Clean, minimalist UI with hover animations
